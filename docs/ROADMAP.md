# Roadmap

## v0.1.0

- Professor authentication
- Courses and terms
- Scheduled appointment slots
- Live walk-in queue
- Student intake form
- QR code generation
- Secure student status page
- Server-sent live updates
- Professor live queue dashboard
- Student on-my-way/check-in actions
- Late/no-show statuses
- Email notification abstraction
- Opening alerts data model and subscription page
- Basic waitlist data model
- Basic analytics and CSV export
- Supabase RLS policies
- Automated core tests and CI

## v0.2

- Google Calendar and Outlook calendar integration
- Better recurring schedule generator
- Calendar invite attachments

## v0.3

- Canvas and Blackboard integration
- Course roster import options

## v0.4

- SMS notifications
- Native push notifications
- Consent and compliance workflows for paid messaging

## v0.5

- Department analytics
- Aggregated reports across instructors

## v0.6

- Multiple instructors and TAs per course
- Role-based permissions

## v0.7

- University SSO
- Microsoft/Google sign-in options

## v1.0

- Production-ready faculty office-hours platform
- Full audit trail and retention automation
- Institutional deployment playbook

## Deliberately not in v0.1

- payment processing
- AI advising
- AI grading
- student grades
- recommendation-letter writing
- full private messaging network
- native mobile apps
